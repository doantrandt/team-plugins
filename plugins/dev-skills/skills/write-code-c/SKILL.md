\---

description: Viết code C theo chuẩn của nhóm Dev (cấu trúc, style, error handling)

\---



Khi được yêu cầu viết code C, hãy:



1\. Viết code rõ ràng, có comment khi cần.

2\. Tuân thủ naming convention của dự án (nếu có).

3\. Xử lý lỗi và edge case hợp lý.

4\. Ưu tiên an toàn bộ nhớ (tránh buffer overflow, memory leak).

5\. Đưa ra ví dụ sử dụng ngắn nếu phù hợp.



Nếu yêu cầu chưa rõ (platform, compiler, ràng buộc), hãy hỏi lại trước khi viết.
