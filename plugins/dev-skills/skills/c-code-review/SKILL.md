\---

description: Review code C theo chuẩn của nhóm Dev

\---



Khi được yêu cầu review code C, hãy kiểm tra:

\- Memory safety (buffer overflow, use-after-free...)

\- Style và naming convention của dự án

\- Edge case và error handling

\- Performance nếu liên quan



Đưa ra nhận xét rõ ràng, có ví dụ code sửa nếu cần.
